# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that materially affect DevInsight. They explain context and trade-offs so future contributors can understand why the system is shaped as it is.

ADRs use the following lifecycle: `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
